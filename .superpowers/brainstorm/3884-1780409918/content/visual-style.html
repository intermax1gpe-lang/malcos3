¿Qué dirección visual para la landing?

Empresa de intercomunicadores — mercado Lima, Perú. Elige el estilo que mejor representa la marca.

A — Corporate Secure (Recomendado)

Fondo azul marino oscuro, acentos azul eléctrico. Transmite autoridad, seguridad y confianza institucional. Estilo usado por marcas como Hikvision, Axis, Bosch Security.

B — Clean Professional

Fondo blanco/gris claro, azul acero como color primario. Aspecto corporativo limpio y moderno. Ideal si el público también incluye arquitectos, constructoras o condominios.

C — Dark Tech

Fondo gris grafito / negro, acentos cian/teal. Moderno y tecnológico. Atractivo para públicos jóvenes o empresas tech-forward, pero puede sentirse menos "institucional".
